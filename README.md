# FishBase — база риб для GitHub Pages

Адаптивний українськомовний сайт для зберігання риболовних записів. Працює як статичний сайт: не потребує сервера, збірки, npm чи API-ключів.

## Можливості

- Додавання, редагування та видалення записів.
- Поля: назва риби, карта, локація, наживка, час, тип снасті, глибина, примітка.
- Підказки для карт, локацій, наживок і снастей.
- Список локацій у формі підказує значення, що вже є на вибраній карті. Нову локацію теж можна ввести вручну.
- Комбіновані фільтри за картою, локацією, наживкою, часом і типом снасті.
- Пошук за будь-яким текстом у записі.
- Імпорт та експорт JSON і CSV.
- Дані зберігаються в `localStorage` браузера.

## Важливо про спільне редагування

GitHub Pages — це хостинг статичних файлів, а не спільна база даних. У цій версії кожен браузер має власні дані. Гравці можуть обмінюватися резервними файлами JSON/CSV:
1. Один учасник експортує актуальний `fishbase-backup.json`.
2. Інші імпортують його та обирають заміну бази або об'єднання з наявними записами.
3. Після внесення змін учасник експортує оновлений файл і надсилає його всім.

Автоматичної синхронізації в реальному часі або захисту від одночасних конфліктних змін немає. Для справжньої спільної бази потрібен окремий бекенд, наприклад Supabase або Firebase, із правилами доступу й автентифікацією. Не зберігайте секретні ключі в коді, опублікованому на GitHub Pages.

## Публікація на GitHub Pages

1. Увійдіть на [GitHub](https://github.com/) або створіть акаунт.
2. Створіть новий репозиторій, наприклад `fishbase`.
3. Завантажте в корінь репозиторію файли `index.html`, `styles.css`, `app.js` та `README.md`. Можна також завантажити `sample-data.json`, якщо хочете мати приклад для імпорту.
4. Відкрийте репозиторій → **Settings** → **Pages**.
5. У розділі **Build and deployment** виберіть **Deploy from a branch**.
6. У **Branch** виберіть `main`, а папку — `/(root)`, після чого натисніть **Save**.
7. Зачекайте кілька хвилин. Сторінка GitHub Pages покаже URL сайту, зазвичай `https://ВАШ-ЛОГІН.github.io/fishbase/`.

Якщо змінили файли, оновіть їх у репозиторії — GitHub Pages опублікує нову версію автоматично.

## Як користуватися

- Натисніть **Додати запис**, введіть назву, карту та локацію. Назва, карта й локація обов'язкові.
- Підказки локацій залежать від введеної карти, але дозволяють додати нову локацію вручну.
- Кнопки ✎ і × на картці дозволяють редагувати й видаляти запис.
- У пошуку комбінуйте кілька фільтрів. Локації в фільтрі стають доступними після вибору карти.
- **Експорт JSON** — рекомендована повна резервна копія.
- **Експорт CSV** — зручно відкривати в табличних редакторах.
- Під час імпорту натисніть OK, щоб замінити поточну базу, або Cancel, щоб об'єднати записи. Точні дублікати під час об'єднання пропускаються.

## Резервне копіювання

Експортуйте JSON регулярно та зберігайте копію поза браузером. Очищення даних сайту, використання іншого браузера або іншого пристрою не переносить локальні записи автоматично.

## Структура проєкту

```text
fishbase/
├── index.html
├── styles.css
├── app.js
├── README.md
└── sample-data.json
```

Усі файли можна змінювати звичайним текстовим редактором. Для локальної перевірки відкрийте `index.html` у браузері.
